Interview

Interview preparation

The repository interview template, cheat sheets, and every LLD problem you can practice locally on GitHub Pages.

How to answer

  1. Clarify requirements — actors, constraints, and success cases.
  2. Identify entities — classes, enums, and relationships.
  3. Class design — fields, methods, and patterns.
  4. Implementation — write the core flows.
  5. Exception handling — concurrency, invalid input, edge cases.

SOLID at a glance

  • SRP — one reason to change.
  • OCP — open for extension, closed for modification.
  • LSP — subtypes must be substitutable.
  • ISP — no fat interfaces.
  • DIP — depend on abstractions.

DRY · YAGNI · KISS — don't repeat yourself, don't build unused features, keep the design simple.
